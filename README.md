# 六级真题阅读陪练

把一篇六级仔细阅读交给教练，先自己做，交卷后再用中文逐题讲。每轮只追问一个问题，优先处理错题和拿不准的题。

## 在 Codex 使用

1. 克隆或下载这个仓库，然后在仓库根目录打开 Codex。
2. 输入 `$cet6-reading-tutor`，再贴上你的真题原文、题目和选项。已做过的题可以连同答案一起发。也可以用 `/skills` 查找。
3. 用 `?` 标记犹豫的题。如要跳过追问，说“这题直接讲”。

> 我做完了这篇六级仔细阅读。我的答案是 `46B 47D? 48A 49C 50B`。请先讲我错的或拿不准的题，每轮只问我一个问题。

## 在 ChatGPT 使用

打开 [SKILL.md](.agents/skills/cet6-reading-tutor/SKILL.md)。有 Skills 功能时，可以用 Skills 编辑器创建该技能。也可以把文件正文复制到新对话，再提供你手头的真题。

[试做一篇原创练习](examples/reading-practice.md)。本仓库的示例用于体验对话讲解。练真题时，请在自己的对话中添加题目及参考答案（如有）。
